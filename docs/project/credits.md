# Credits and acknowledgments

Momokun builds on Rust, Tokio, Poise, Serenity, Songbird and SQLx, with SQLite
for persistent storage. FFmpeg, FFprobe, yt-dlp and Deno support media workflows.
Material for MkDocs powers this documentation.

The repository preserves security backports in libcrux-chacha20poly1305,
libcrux-secrets and ringbuf; vendor/README.md records provenance and removal
conditions. THIRD_PARTY_NOTICES.md describes license obligations and remaining
distribution checks.

Thanks to upstream maintainers and project contributors. Approved character
references were provided by the owner; artist credit and distributable original
files remain to be confirmed before artwork is packaged. Service names belong
