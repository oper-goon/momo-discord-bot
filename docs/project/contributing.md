# Contributing

Report reproducible problems with your version, install method, expected result
and redacted diagnostic output. Never upload `.env`, private configuration,
SQLite files or signed media URLs.

For code, use a focused branch, follow AGENTS.md and preserve module boundaries.
Include documentation changes whenever commands, configuration, integrations,
dependencies, deployment, persistence or user-visible behavior change. Run Rust
and documentation validation and state any missing live Discord checks in the
pull request.

The repository's CONTRIBUTING.md contains the contribution policy. SECURITY.md
describes private vulnerability reporting; CODE_OF_CONDUCT.md sets community
expectations. No CLA is currently required. Discuss large changes before
implementation to avoid work that conflicts with the release plan.
