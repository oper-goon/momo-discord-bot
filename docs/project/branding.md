# Momokun branding

The owner supplied approved anime character and banner references during release
preparation. The visual identity is monochrome, with charcoal surfaces, light
text and restrained glitch details. Do not invent a replacement mascot or use
unlicensed third-party anime imagery.

The local release candidate includes AI-generated derivatives created from the
owner's uploaded references: a navigation wordmark, eye-and-horns emblem, and
mascot banner. These are review candidates, not original source artwork. Confirm
the reference artwork's provenance and approve the derivatives before publication.
The website supports these integration points:

| File under docs/assets/brand/ | Use |
| --- | --- |
| momokun-banner.webp | Home hero artwork |
| momokun-wordmark.webp or momokun-wordmark.png | Navigation logo |
| favicon.png | Small recognizable browser icon |
| momokun-social.png | Social sharing image and home banner fallback |
| momokun-mascot.webp | Reserved mascot artwork integration |

The current text-based theme remains usable when those files are absent. Export
optimized images, retain useful alternative text and check small-screen crops.
Use a simplified emblem for the favicon; avoid tiny unreadable wordmarks.
Respect reduced-motion preferences and keep decorative effects subtle.

Do not imply an unofficial fork, hosting service or commercial offering is the
official Momokun project. The software license does not itself establish rights
to the name, logo or mascot. Ask the owner before using the identity to endorse
or promote a separate service. Ownership and any broader branding permission
must be confirmed before publishing formal trademark claims.
