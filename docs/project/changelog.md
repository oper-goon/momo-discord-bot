# Changelog and release status

The repository's CHANGELOG.md is the authoritative version history. The current
workspace version is 0.9.0. Read its release notes before updating, keep a verified
database backup, and check whether the release changes configuration or storage.

The public documentation, container-image plans and proposed licensing
materials are release preparation work. They do not imply that an image has
been published, a site deployed, or a license transition approved. Known
validation gaps must be resolved before the owner approves public release.
